ARYA TRADING JOURNAL V6 — FRESH BUILD

Isi ZIP:
- index.html: aplikasi utama (HTML/CSS/JS mandiri)
- manifest.webmanifest + icon.svg: dukungan instalasi PWA
- sw.js: cache offline sederhana

Cara pakai:
1. Ekstrak ZIP.
2. Upload seluruh isi folder ke GitHub Pages / hosting statis.
3. Buka URL website dari Safari iPhone.
4. Tekan Share > Add to Home Screen.

Fitur:
- Dashboard dan ringkasan P/L, win rate, jumlah trade, best trade, P/L bulanan, average R/R.
- Equity Curve berdasarkan trade yang dicatat.
- Form trade: XAUUSD, NAS100, BTCUSD, EURUSD; Buy/Sell; tanggal; lot 0.01–0.50; Entry, SL, TP; Risk Amount; hasil TP/SL; R/R otomatis.
- Journal, kalender, analytics per pair.
- Export CSV, backup JSON, restore JSON.
- Data tersimpan lokal di browser/perangkat melalui localStorage.

Catatan:
Versi ini dibuat baru dari nol, tidak memakai source code versi lama. Data versi lama tidak otomatis dipindahkan. Sebelum menghapus/meninggalkan aplikasi lama, ekspor atau simpan backup jika masih diperlukan.
